# 🚀 Docker Express TypeScript & MySQL Template

A ready-to-use production template featuring **Node.js 22**, **Express**, **TypeScript**, **MySQL 8.4**, and **phpMyAdmin** fully dockerized.

---

## ⚡ Quick Start

```powershell
# Run automated setup
npm run setup
```

- **Express App**: `http://localhost:8000`
- **DB Test Route**: `http://localhost:8000/db-test`
- **phpMyAdmin UI**: `http://localhost:8080` (User: `root`, Pass: `root_password`)
